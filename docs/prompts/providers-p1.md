1. Contracts (server/providers/contracts.js, JSDoc typedefs):
   - Messages: { role: 'system'|'user'|'assistant', content: string | Part[] }; Part = {type:'text', text} | {type:'image', mime, base64}.
   - LlmProvider.stream({messages, temperature?, maxTokens?, json?, signal?, timeouts?}) -> AsyncIterable of {type:'text', delta} | {type:'usage', inputTokens?, outputTokens?} | {type:'done', finishReason?}; complete() convenience; optional warmup(). Vision = LlmProvider called with an image part (capability flag), no separate interface.
   - SttProvider.transcribe({audio: Buffer, mime, filename, language?, signal?}) -> {text, segments?: [{text, noSpeechProb?, avgLogprob?, compressionRatio?}], durationMs?}. Missing fields stay absent; the existing hallucination filter must skip checks whose inputs are missing instead of failing.
   - TtsProvider.stream({text, emotion?, voice?, format?, signal?}) -> AsyncIterable<{type:'audio', data: Buffer, format}>.
   - ImageProvider unchanged.
   - Adapters declare capabilities {llm, images, jsonMode, stt, tts}; profile/model can override.
2. errors.js: ProviderError {code: AUTH|RATE_LIMIT|TIMEOUT|BAD_REQUEST|SERVER|NETWORK|UNSUPPORTED|ABORTED|BAD_RESPONSE, status?, retryAfterMs?, providerId, slot, safe redacted message}. Consistent mapping; honor Retry-After.
3. Resilience helper: timeouts (firstByteMs, idleMs, totalMs; per-slot configurable); retry ONLY before any output was yielded (max 2, exponential backoff + jitter, only RATE_LIMIT/SERVER/NETWORK); NEVER retry after partial output (would duplicate speech). AbortSignal everywhere; abort closes sockets/streams promptly and surfaces ABORTED.
4. sse.js: SSE parser for fetch responses (chunk boundaries, multi-line data, comments, [DONE], CRLF).
5. Adapters (server/providers/adapters/):
   a. openaiCompatible.js: baseUrl, secret via resolver, extraHeaders, profile flags (supportsJsonMode, supportsStreamUsage, supportsImages). llm.stream = POST {baseUrl}/chat/completions with stream:true; json -> response_format json_object only if supportsJsonMode, else prompt-only; images -> image_url data URIs; reasoning deltas (reasoning/reasoning_content) are ignored, only content deltas become text; profile bodyExtras (e.g. reasoning_effort) and omitParams for servers that reject parameters. stt.transcribe = multipart POST {baseUrl}/audio/transcriptions (verbose_json when supported) normalized to SttProvider. tts unsupported.
   b. anthropicNative.js: POST {baseUrl or the official default}/v1/messages with x-api-key and a configurable anthropic-version header; system messages -> top-level system; images as base64 source blocks; max_tokens required (profile default); normalize the streaming events (message start, text delta, usage, stop, error). json flag handled by prompt only in P1. Verify event/field names against the official docs while implementing; no model ID hardcoded.
   c. fishAudio.js: move the existing Fish Audio WebSocket/MessagePack logic here unchanged (endpoint, model id, reference_id from voiceConfig, emotion tags, start/text/flush/stop protocol, abort closes the socket). Existing TTS tests move over, not weakened.
